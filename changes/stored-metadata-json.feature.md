`ArraySpec`, `BaseGroupSpec` and `GroupSpec` (v2 and v3) gain a `to_stored_metadata_json()` method that returns the node's metadata as a Zarr store holds it: a mapping from each store key to the JSON document stored there, statically typed per key. For v3 that is `{"zarr.json": ...}` (`ZarrV3ArrayStoredJSON` / `ZarrV3GroupStoredJSON`); for v2 it is `.zarray` or `.zgroup` plus `.zattrs` (`ZarrV2ArrayStoredJSON` / `ZarrV2GroupStoredJSON`), with `.zattrs` written even when the attributes are empty, as zarr-python writes it. A group's members are left out.
