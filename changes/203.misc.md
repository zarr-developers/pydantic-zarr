pydantic-zarr reads `zarr-metadata`'s scopes by the names the next `zarr-metadata` release gives them (`CORE_CONTEXT`, `CORE_AND_EXTENSIONS_CONTEXT`), falling back to the 0.6 names where only those exist, so it imports without a `DeprecationWarning` on either version. The tests build their custom scopes with `ZarrV3Context.union`, which both versions have, instead of `update`, which the next release removes.
