Four worked examples join the documentation, one per real-world layout the API was exercised against: OME-Zarr 0.5 and 0.6 images, a GeoZarr Sentinel-2 product, and xarray-style datasets. Each shows the typed-attributes and typed-members patterns (closed `TypedDict` member sets, `AttributesBase` attribute models, `from_shape_and_data_type`, `resolve_path`/`get_path`, cross-member validators), round-trips its hierarchy through a store, and demonstrates the refusals the model enforces; every code block runs in the documentation test suite.
