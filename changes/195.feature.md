`ArraySpec`, `BaseGroupSpec` and `GroupSpec` (v2 and v3) gain a `to_json()` method that returns the node's metadata document, statically typed with the `zarr-metadata` document types: `ZarrV3ArrayMetadataJSON` / `ZarrV3GroupMetadataJSON` for v3, and the merged `ZarrV2ArrayMetadataJSON` / `ZarrV2GroupMetadataJSON` (the `.zarray` / `.zgroup` fields plus `attributes` from `.zattrs`) for v2. Unlike `model_dump`, it takes no options, so its return type is exact. Extra fields (such as `consolidated_metadata`) are written as top-level members, and a group's `members`, which are not part of its metadata document, are left out.
