CI jobs now run the `justfile` recipes instead of calling hatch, uv and pip directly, so a local `just` run is the same command CI runs. New recipes `lock-check`, `test-min-reqs`, `test-base-cov`, `test-base-all` and `ci` cover the CI checks that had no recipe, and the `list-env` hatch script now lists the hatch environment's packages with uv instead of calling a `pip` that the uv-installed environments do not have.
