CI now runs three type checkers, each covering the others' blind spots: pyrefly (the project checker, repo-wide), and ty and pyright over a new `tests/typing_conformance.py` holding the parameterizations downstream code writes (ty also covers the modules it is clean on today). pyrefly is variance-lenient, and mypy — evaluated and passed over — does not apply PEP 696 TypeVar defaults inside the lazy `type` aliases, so the invariant-bound regression this release fixes was visible only to ty and pyright, both verified to refuse it.
