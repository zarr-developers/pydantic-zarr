CI jobs now run the `justfile` recipes instead of calling hatch, uv and pip directly, so a local `just` run is the same command CI runs. New recipes `lock-check`, `test-min-reqs`, `test-base-cov`, `test-base-all` and `ci` cover the CI checks that had no recipe. Linting runs the existing `.pre-commit-config.yaml` hooks (ruff linting with import sorting, ruff formatting, codespell, zizmor and others) with prek instead of pre-commit, both in `just lint`/`just setup` and in CI. The `list-env` hatch script now lists the hatch environment's packages with uv instead of calling a `pip` that the uv-installed environments do not have.
