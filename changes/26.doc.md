`read_documents` in `examples/zarr_io.py` now reads consolidated hierarchies: it leaves out a Zarr V2 group's `.zmetadata` and a V3 group's `consolidated_metadata`, so a consolidated group reads back as the spec that was written, as it did with `from_zarr`. Before, a consolidated V2 group raised `Unrecognized store key '.zmetadata'`, and a consolidated V3 group kept `consolidated_metadata` on every group. Projects that copied `read_documents` should copy it again.
