Fixed group member type parameters refusing narrowed specs under strict type checkers: `GroupSpec[Attrs, MyArraySpec]` — a group parameterized with a narrowed member spec — is accepted by mypy and pyright, where the `TItem` bound previously resolved through its PEP 696 defaults to invariant `TBaseAttr` specializations that refuse narrowed specs. The spec type parameters are covariant, which is what makes the narrowed parameterizations ordinary subtypes.
