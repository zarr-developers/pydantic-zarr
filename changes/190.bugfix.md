Fixed group member type parameters refusing narrowed specs under strict type checkers: the bound of `TItem` is now `TAnyItem`, a union of Any-parameterized spec classes, where it previously shared `TBaseItem`'s bare class names, which resolve through their PEP 696 defaults to invariant `TBaseAttr` specializations that mypy and pyright refuse a `GroupSpec[Attrs, MyArraySpec]` parameterization for (v2 and v3 alike). `TBaseItem` itself — `TItem`'s default, and so the runtime schema of a bare `GroupSpec`'s members — keeps the bare, recursive spelling, which validates nested members as specs all the way down.
