`pydantic_zarr.v3.normalize_group_metadata` repairs a stored Zarr V3 group document before it is validated. With `normalize_null_consolidated_metadata` (on by default), it drops the `"consolidated_metadata": null` that zarr-python 3.0 writes into every group, which the spec does not allow; every other JSON value is returned as it is. Apply it to each document of a stored-documents mapping before `from_stored_metadata_json`.
