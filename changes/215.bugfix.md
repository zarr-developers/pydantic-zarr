`pydantic_zarr.v2.auto_chunks` raises `ValueError` for an object without `chunksize`, `chunks`, or `shape` and `dtype`, and `pydantic_zarr.v2.dtype_default_fill_value` is annotated to take an `npt.DTypeLike`. The library's annotations use precise types instead of `typing.Any`, which surfaced and fixed values that were passed unchecked to typed APIs.
