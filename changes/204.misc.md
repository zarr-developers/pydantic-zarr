The test suite draws Zarr V3 array and group documents from `zarr-metadata`'s Hypothesis strategies (`zarr_metadata.testing.strategies`, new in `zarr-metadata` 0.7.0 behind its `testing` extra, which the test dependencies now include), in every envelope spelling and from every definition they hold. It checks that `ArraySpec` and `BaseGroupSpec` read everything `zarr-metadata` draws as valid, as the spec its canonical spelling gives, that they write back what `zarr-metadata` reads without a problem, and that `ArraySpec.like` judges two fill-value spellings the same exactly when `zarr-metadata`'s models do. The tests are skipped where the strategies are not installed.
