`GroupSpec` is no longer a subclass of `BaseGroupSpec`, in `pydantic_zarr.v2` and `pydantic_zarr.v3`. Both build on a shared private base, and neither is a kind of the other: a `GroupSpec` is a hierarchy, and a `BaseGroupSpec` is one group's own metadata. So `isinstance(group, BaseGroupSpec)` and `is_base_group_spec(group)` are now false for a `GroupSpec`, and a `GroupSpec` is refused where a `BaseGroupSpec` is expected, such as `BaseGroupSpec.model_validate(group)`. To check for either kind of group, use `isinstance(node, GroupSpec | BaseGroupSpec)`. To get a hierarchy's root as a `BaseGroupSpec`, use `GroupSpec.own_metadata()`.
