pydantic-zarr requires `zarr-metadata` 0.8.0 or later, and reads its scopes only by their `*_CONTEXT` names. A v2 spec built without a fill value, or by `from_array` from an array with none, gets the default `zarr-metadata` 0.8.0 derives for its dtype, which is the value zarr-python uses, where it used to get `0` when the dtype accepted `0` and `None` otherwise: `False` for `|b1`, `(0.0, 0.0)` for complex dtypes, the empty string for `|S` and `<U`, null bytes (in base64) for raw and struct dtypes, `"NaT"` for the time dtypes where they got `0` (the epoch), and `None` for `|O` where it got `0`. A float dtype gets `0.0`, the same value as `0` written as a float.
