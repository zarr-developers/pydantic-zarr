Type checking now has a single entry point: the `types` hatch environment, run as `hatch run types:check` and by a new `typecheck` CI job. The environment installs the `test` dependency group, so mypy sees the same `zarr`, `pytest`, `xarray` and `dask` versions the tests use, and mypy is pinned. The `mypy` pre-commit hook has been removed, since it checked only `src` with a separately-pinned mypy and could drift from CI. `tests/` is now type-checked and clean.
