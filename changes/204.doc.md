The Zarr V3 usage guide uses the scope names `zarr-metadata` 0.7.0 introduced (`CORE_CONTEXT`, `CORE_AND_EXTENSIONS_CONTEXT`), and says which scopes claim the variable-length data types and codecs: `CORE_AND_EXTENSIONS_CONTEXT` claims `string`, `bytes`, `vlen-utf8` and `vlen-bytes` from 0.7.0, `ZARR_PYTHON_CONTEXT` also claims `variable_length_bytes`, and no scope claims `"str"`.
