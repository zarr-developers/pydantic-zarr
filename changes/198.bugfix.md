`pydantic_zarr.v2.ArraySpec` now holds its fill value in the Zarr V2 JSON form, as the v3 spec already did. Non-finite floats become the strings `"NaN"`, `"Infinity"` and `"-Infinity"`, so `json.dumps` of `model_dump()` no longer writes a bare `NaN` that strict JSON parsers reject. Numpy scalars become Python scalars: an `np.int16` fill value was previously stored as a float, and the imaginary part of an `np.complex64` was dropped. Complex numbers (Python or numpy) become `(real, imaginary)` pairs, in both the v2 and v3 specs. `canonicalize_fill_value` moves to `pydantic_zarr.core` and is still importable from `pydantic_zarr.v3`.
