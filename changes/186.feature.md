`ArraySpec`, `BaseGroupSpec` and `GroupSpec` (v2 and v3) gain a typed `replace(**changes)` method: it returns a revalidated copy with the changes applied in one validation pass, so correlated fields (a new `data_type` with a matching `fill_value`, a new `shape` with a matching `chunk_grid`) change together atomically — which per-field builders cannot express — and, unlike `model_copy(update=...)`, the result is always validated. The name follows Python's for a changed copy of an immutable value (`str.replace`, `datetime.replace`, `dataclasses.replace`) and `zarr-metadata`'s models, and each spec defines `__replace__` as the same method, so `copy.replace(spec, shape=(8,))` on Python 3.13 and later validates too, where pydantic's own `__replace__` copies without validating. The keyword arguments are statically typed via `Unpack` of per-model `*Update` TypedDicts. This replaces the (never-released) `with_*` builder methods.
