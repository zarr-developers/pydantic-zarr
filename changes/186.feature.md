`ArraySpec`, `BaseGroupSpec` and `GroupSpec` (v2 and v3) gain a typed `update(**changes)` method: it returns a revalidated copy with the changes applied in one validation pass, so correlated fields (a new `data_type` with a matching `fill_value`, a new `shape` with a matching `chunk_grid`) change together atomically — which per-field builders cannot express — and, unlike `model_copy(update=...)`, the result is always validated. The keyword arguments are statically typed via `Unpack` of per-model `*Update` TypedDicts. This replaces the (never-released) `with_*` builder methods.
