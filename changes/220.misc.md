The `auto_*` readers behind `ArraySpec.from_array` (v2 and v3) check what they read from the array before returning it, and raise `TypeError` for a value of the wrong type, where they returned it unchecked for validation to reject. A chunk shape is read as a tuple of Python ints, so numpy integers are accepted. `pydantic_zarr.v2.auto_attributes`, `auto_compresser` and `auto_filters` are annotated with the values they already returned for a spec: a pydantic model of attributes, and codecs in JSON form. `auto_filters` always returns a list. pyright and ty now check every library module except `pydantic_zarr.experimental`.
