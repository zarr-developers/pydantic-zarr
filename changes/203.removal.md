`ArraySpec.chunk_grid` and `ArraySpec.chunk_key_encoding` are typed as `ChunkGridLike` and `ChunkKeyEncodingLike` (both in `pydantic_zarr.v3`): the core spec's declarations, typed exactly as before, or any other declaration as a named configuration. Every value the fields took before still type-checks as input, but a static type checker no longer knows a stored chunk grid is the regular one, so code that reads `spec.chunk_grid["configuration"]["chunk_shape"]` needs a narrowing (check `spec.chunk_grid["name"] == "regular"` and cast, for instance). The model validator `ArraySpec.canonicalize_codecs` is renamed `canonicalize_declarations`, since it now normalizes every declaration's envelope, not only the codecs'.
