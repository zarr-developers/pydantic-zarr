`ArraySpec.chunk_grid` and `ArraySpec.chunk_key_encoding` hold any declaration the scope judges, not only the core spec's, so a static type checker no longer knows a stored chunk grid is the regular one: code that reads `spec.chunk_grid["configuration"]["chunk_shape"]` needs a narrowing (check `spec.chunk_grid["name"] == "regular"` and cast, for instance). The model validator `ArraySpec.canonicalize_codecs` is renamed `canonicalize_declarations`, since it now normalizes every declaration's envelope, not only the codecs'.
