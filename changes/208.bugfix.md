`ArraySpec.from_array`, `create_default` and `parse_dtype_v3` read numpy's fixed-length unicode, bytes, void and variable-length `StringDType` types, spelled as zarr-python writes them (`fixed_length_utf32`, `null_terminated_bytes`, `raw_bytes` where the scope claims it and the core `r<bits>` otherwise, and `string`), and `from_array` derives a numpy array's fill value and codecs in the class's scope. The `bytes` codec's no-op endian is dropped for every data type the scope declares single-byte, and `create_default`, `replace` and `from_array` accept `zarr_metadata`'s typed codec, chunk grid and chunk key encoding objects for a type checker.
