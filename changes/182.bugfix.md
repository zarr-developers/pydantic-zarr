Fixed `pydantic_zarr.v3.ArraySpec.from_array` raising `ValueError` for every `bool` array: `auto_fill_value` tested the dtype character `"?"` where numpy reports the *kind* `"b"`, so the bool branch was unreachable. `from_array` also no longer emits invalid data type names for non-core numpy dtypes (such as `"datetime64[ns]"`), since the data type is now derived via `parse_dtype_v3` instead of `str(array.dtype)`.
