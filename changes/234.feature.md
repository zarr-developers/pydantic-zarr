Array and group specs in `pydantic_zarr.v2` and `pydantic_zarr.v3` have a new `diff` method. `a.diff(b)` returns the JSON Patch (RFC 6902) that turns `a.model_dump()` into `b.model_dump()`. With `semantic=True`, it returns only the operations that change what the metadata means, as `zarr-metadata` reads it. For example, a float32 fill value written `"NaN"` means the same as one written `"0x7fc00000"`. Comparing an array with a group raises `ValueError`, and so does comparing a `GroupSpec` with a `BaseGroupSpec`. The new `pydantic_zarr.core.json_patch` builds the same kind of patch between any two JSON-like values.
