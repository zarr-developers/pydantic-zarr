`GroupSpec`'s second type parameter is no longer the type of one member: write `GroupSpec[Attrs, Mapping[str, MyArraySpec]]` where 0.11 took `GroupSpec[Attrs, MyArraySpec]`. A class still written the old way fails validation, since its whole members mapping is validated as one member: the errors describe the members mapping as if it were one member (such as `members.shape  Field required` for an array type) and do not mention the change of parameter. Type checkers refuse it where it is written. The `TItem` type variable is removed; `TMembers` and `TBaseMembers` replace it, and `AnyGroupSpec` is `GroupSpec[TBaseAttr, TBaseMembers]`.
