`GroupSpec`'s second type parameter is no longer the type of one member: write `GroupSpec[Attrs, Mapping[str, MyArraySpec]]` where 0.11 took `GroupSpec[Attrs, MyArraySpec]`. A class still written the old way fails validation, since its whole members mapping is validated as one member: the errors name the member type's fields under `members` (such as `members.shape  Field required`), or say that `members` must be a mapping. Type checkers refuse it where it is written. The `TItem` type variable is removed; `TMembers` and `TBaseMembers` replace it, and `AnyGroupSpec` is `GroupSpec[TBaseAttr, TBaseMembers]`.
