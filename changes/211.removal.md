`GroupSpec`'s second type parameter is no longer the type of one member: write `GroupSpec[Attrs, Mapping[str, MyArraySpec]]` where 0.11 took `GroupSpec[Attrs, MyArraySpec]`. A class still written the old way fails validation, since its whole members mapping is validated as one member, and type checkers refuse it where it is written. The `TItem` type variable is removed; `TMembers` and `TBaseMembers` replace it, and `AnyGroupSpec` is `GroupSpec[TBaseAttr, TBaseMembers]`.
