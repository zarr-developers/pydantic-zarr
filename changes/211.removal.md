`GroupSpec`'s second type parameter is no longer the type of one member: write `GroupSpec[Attrs, Mapping[str, MyArraySpec]]` where 0.11 took `GroupSpec[Attrs, MyArraySpec]`. A class still written the old way raises a `TypeError` that names the replacement when it first validates members, and type checkers refuse it where it is written. The `TItem` type variable is removed; `TMembers` and `TBaseMembers` replace it, and `AnyGroupSpec` is `GroupSpec[TBaseAttr, TBaseMembers]`.
