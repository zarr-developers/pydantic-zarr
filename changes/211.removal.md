`GroupSpec`'s second type parameter is no longer the type of one member: write `GroupSpec[Attrs, Mapping[str, MyArraySpec]]` where 0.11 took `GroupSpec[Attrs, MyArraySpec]`. The old spelling is deprecated: it still works at runtime, read as that mapping, with a `DeprecationWarning`, and type checkers refuse it. The `TItem` type variable is removed; `TMembers` and `TBaseMembers` replace it, and `AnyGroupSpec` is `GroupSpec[TBaseAttr, TBaseMembers]`.
