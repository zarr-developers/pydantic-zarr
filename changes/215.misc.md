Replaced `typing.Any` in the library's annotations with precise types, which surfaced and fixed values that were passed unchecked to typed APIs. A group's deprecated `to_zarr` now types its extra keyword arguments as the `config` its array members take, `pydantic_zarr.v2.dtype_default_fill_value` takes an `npt.DTypeLike`, and `pydantic_zarr.v2.auto_chunks` raises `ValueError` for an object without `chunksize`, `chunks`, or `shape` and `dtype`.
